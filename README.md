# Banking-with-java
## Description
ACME Bank is a simple banking app. Bankers can add new customers, and customers can manage their savings and checking accounts: deposit, withdraw, transfer money, and see their transaction history. Everything is saved, so nothing is lost when the app is closed.

## Technologies used
* Java programming lanaguage
* IntelliJ

## User Stories
* As a banker, I want to log in and add new customers, so that they can start using the bank.
* As a user, I want to log in securely with my username and password, and the system should know if I am a banker or a customer.
* As a user, I want my password to be encrypted, so that nobody can read it from the files.
* As a customer, I want to deposit and withdraw money from my savings or checking account.
* As a customer, I want to transfer money between my own accounts or to another customer's account.
* As a customer, I want to reactivate my account after I clear the negative balance.
* As a customer, I want to upgrade my debit card to get higher limits.
* As a customer, I want to view a history of all my transactions to track my spending and deposits.
* As a customer, I want to filter my transactions (for example today or yesterday), so that I can find them quickly.

## Favorite Functions
* My favorite part is the Transactions class, because it connects most of the other classes together: accounts, debit cards, files and the transaction history.
